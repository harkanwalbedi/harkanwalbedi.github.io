Self-hosted web fonts
=====================

These are the Latin-subset WOFF2 files that Google Fonts serves, hosted here so
the site makes no third-party requests.

  inter-latin-var.woff2            Inter, variable weight 400-700
  jetbrains-mono-latin-var.woff2   JetBrains Mono, variable weight 400-700
  newsreader-600-latin-opsz.woff2  Newsreader, weight 600, variable optical size 6-72

Sources
  https://fonts.google.com/specimen/Inter
  https://fonts.google.com/specimen/JetBrains+Mono
  https://fonts.google.com/specimen/Newsreader

Licence
  All three families are licensed under the SIL Open Font License, Version 1.1.
  The copyright notice and full licence text for each family is in the
  LICENSE-*.txt file next to it.

To update a font, download the new Latin WOFF2 from Google Fonts, replace the
file here, and keep the @font-face rules in src/styles/global.css in step.
